# My Wellness — Branch 02: Links, Images, Forms, and Tables

This version is for the second part of Chapter 3.

## What students can learn from this branch

- Relative links between pages in the same folder
- Relative links to a page inside a subfolder
- Parent folder paths using `../`
- Images using `<img src="..." alt="...">`
- Forms with labels, input types, select, textarea, required fields, and buttons
- Tables using `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`

## Suggested branch name

```bash
git checkout -b stage-02-links-images-forms
```

Then add, commit, and push.

# My Wellness — Branch 01: HTML Structure

This version is for the first part of Chapter 3.

## What students can learn from this branch

- Basic HTML page skeleton: `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`
- Semantic layout tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Headings and paragraphs
- Ordered and unordered lists
- Simple anchor links inside the same page

## Suggested branch name

```bash
git checkout -b stage-01-html-structure
```

Then add, commit, and push.

# My Wellness — Branch 03: Style Your Pages with CSS

This version is for Chapter 4 CSS assignment.

## Goal

Students start from the previous branch and add `style.css` to make the home page look like the example in the slide.

## Suggested branch name

```bash
git checkout -b stage-03-css-style-pages
```

## CSS properties used

- `font-family`, `color`, `background-color`, `line-height`
- `padding`, `margin`, `border`, `border-radius`, `text-align`
- `text-decoration`, `width`, `max-width`, `box-sizing`

No `flex` or `grid` is used in this branch.
